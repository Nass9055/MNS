# 🧭 MNS Trade Navigator

**ระบบวิเคราะห์และนำทางการเทรด — สร้างแผนจากโครงสร้างตลาดจริง ปรับตามเวลาและข่าวอัตโนมัติ**

> 📦 ไฟล์เดียวครบ · เปิดใช้งานได้ทันที · รองรับ GitHub Pages

## ✅ คุณสมบัติหลัก

- 📊 **ดึงราคาอัตโนมัติ** จาก Binance API — ทองคำ น้ำมัน คริปโต ฟอเร็กซ์
- 🛡️ **หา SL จากโครงสร้างตลาด** — Liquidity Zone / Sweep High-Low / FVG / Pullback Zone
- 🎯 **กำหนดเป้าหมายจากโครงสร้าง** — ไม่ใช้สูตรคงที่ ปรับตามบริบทตลาดจริง
- 🕐 **ตรวจสอบเวลาเปิดตลาด** — เอเชีย / ยุโรป / อเมริกา / ช่วงซ้อนทับ
- 📰 **แจ้งเตือนช่วงประกาศข่าว** — ปรับระยะ SL/Entry อัตโนมัติตามความผันผวน
- 📈 **แสดงกราฟ TradingView** ในหน้าเดียวกัน
- 💎 **รองรับสินทรัพย์หลายประเภท** — ทอง น้ำมัน คริปโต ฟอเร็กซ์
- 📱 **เหมาะกับมือถือและคอมพิวเตอร์** ปรับหน้าจออัตโนมัติ

## 🚀 วิธีใช้งาน

### วิธีที่ 1 เปิดไฟล์ตรง
1. คัดลอกโค้ด `index.html` ด้านบน
2. บันทึกเป็นไฟล์ชื่อ `index.html`
3. เปิดด้วยเบราว์เซอร์ได้ทันที ✅

### วิธีที่ 2 ผ่าน GitHub Pages
1. สร้าง Repository ที่ GitHub ชื่อ `mns-trade-navigator`
2. อัปโหลดไฟล์ `index.html` และ `README.md`
3. เข้าไปที่ **Settings → Pages**
4. เลือก **Branch: main / Root** → กด Save
5. รอประมาณ 1–3 นาที แล้วเข้าใช้ผ่านที่อยู่:
   `ชื่อคุณ.github.io/mns-trade-navigator/`
