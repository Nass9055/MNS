# 🧭 MNS Pro — Market Navigation System

**Master V1.2 | Fixed Overlap | Production Ready**

> MAP → PLAN → NAVI — วางแผนก่อนราคาถึงเสมอ

---

## ✅ คุณสมบัติหลัก
- 🗺️ **MAP** — ดึงราคาทองคำจริงอัตโนมัติ (XAU/USD) ผ่าน API
- 📋 **PLAN** — คำนวณ SL/TP อัตโนมัติ แยก BUY/SELL Trap
- 🧭 **NAVI** — คำแนะนำ + อายุแผน + สถานะ
- 📈 **TradingView Chart** — กราฟจริงเต็มจอ
- 🔗 **โบรกเกอร์ในตัว** — Mitrade / Exness / TradingView
- 📱 **รองรับมือถือ** — UI ปรับอัตโนมัติ
- 🌐 **GitHub Pages Ready** — เปิดใช้งานได้ทันที

---

## 🚀 วิธีใช้งาน
1. เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์
2. กด **⚡ ดึงราคาปัจจุบันทันที**
3. กด **🗺️ สร้างภาพตลาด + วางแผนการเทรด**
4. ดูผลที่แท็บ **PLAN** และ **NAVI**
5. กด **−** เพื่อซ่อนแผง → ดูกราฟเต็มจอ
